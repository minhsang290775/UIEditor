UIEditor là tool chưa hoàn thiện, chỉ dùng để xem các layout trong interface của game tlbb, mỗi lân xem được một layout
Cách dùng:
B1. Dùng tool AxpExtract bung Interface.axp vào một folder 
B2. Thay thế các đường dẫn trong UIResources.cfg
B3. Chạy UIEditor, mở từng layout xem
B4. Sửa tay layout bằng notepad++ hoặc visual studio code rồi load layout lại
B5. Dùng AxpPack pack lại bỏ vào game

Enjoy
