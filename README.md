# UIEditor

UIEditor là tool chưa hoàn thiện, chỉ dùng để xem các layout trong interface của game TLBB.  
Mỗi lần chỉ xem được một layout.

## Cách dùng

1. Dùng tool `AxpExtract` bung `Interface.axp` vào một folder.
2. Thay thế các đường dẫn trong `UIResources.cfg`.
3. Chạy `UIEditor`, mở từng layout để xem.
4. Sửa layout bằng `Notepad++` hoặc `Visual Studio Code`, sau đó reload layout.
5. Dùng `AxpPack` pack lại và bỏ vào game.

## Ghi chú

- Tool chỉ phục vụ việc xem/chỉnh sửa layout giao diện.
- Không hỗ trợ chỉnh sửa trực tiếp trong editor.

Enjoy.
